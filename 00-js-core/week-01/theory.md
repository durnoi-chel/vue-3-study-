Замыкание это функция, которая помнит переменные из места своего создания.

Все функции автоматически запоминают своё окружение  никакой специальной магии или особых действий не требуется.

Переменные  это свойства внутреннего хранилища (объекта окружения), к которым функция получает доступ через скрытую ссылку.
